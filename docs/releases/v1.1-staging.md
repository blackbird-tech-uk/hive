# HIVE V1.1 — release candidate staging

Status: **NOT DEPLOYED**. This branch starts from `main` and intentionally does not include PR #42's Android Agent work.

## Proposed scope
- Web fleet map pins and event map areas
- API map-area endpoints and event organisation isolation
- Scanner assignment-to-area support
- PostgreSQL migration `f31a6b8c02e4`

## Required before merging changes
1. Port the web/API changes from `feature/fleet-map-pins-zones` as a coherent set; do not copy the Android Agent changes.
2. Run API/Web CI and isolated PostgreSQL upgrade/downgrade checks on this branch.
3. Inspect production Alembic revision, event ownership, backup and restore readiness.
4. Confirm rollback plan; the migration downgrade removes data.
5. Obtain deployment approval after the release candidate passes.

## Change notes
- **Fleet map:** map pins, drawn zones, styling and API integration.
- **Events:** organisation-scoped event access and persisted polygon areas.
- **Assignments:** optional map area reference for scanners.
- **Security:** tenant-isolation checks and regression tests.

This document is a release plan, not evidence that any of these features have already been ported or deployed.
